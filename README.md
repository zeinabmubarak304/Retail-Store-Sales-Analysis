# Retail-Store-Sales-Analysis
Retail store sales analysis using Microsoft Excel, data cleaning, Pivot Tables and interactive dashboard.
•	Cleaned and validated 12,575 transactions, imputing 604 missing quantities with category medians (flagged for transparency);

Project Overview

This project analyzes retail store sales data to identify sales trends, customer purchasing behavior, product performance, and revenue patterns using Microsoft Excel.

Objectives

Analyze overall retail sales performance.
Identify top-performing product categories.
Understand customer purchasing behavior.
Evaluate sales trends over time.
Build an interactive dashboard.
